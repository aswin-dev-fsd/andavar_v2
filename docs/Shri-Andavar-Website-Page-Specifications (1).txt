HOW TO USE THIS DOCUMENT
────────────────────────────────────────────────────────────────────────────────
PART 0 is the design system. It applies to every page without exception. If you
are handing a single page to a junior or to an AI tool, paste PART 0 first, then
that page's section. Without PART 0 the page will not match the rest of the site.

PART 1 is the shared shell — header, sticky call bar, footer. Identical on all
nine pages. Build it once.

PARTS 2–10 are the nine pages. Each has:
   A · THE BRIEF        what the page is for and who is reading it
   B · SECTION SPEC     every section in order, with the exact copy
   C · WIREFRAME        desktop and mobile, drawn
   D · PAGE RULES       anything specific to this page

PART 11 is the consistency checklist. Run it before anything ships.

Copy marked "EXACT" is final and must be used verbatim. Copy marked
"PLACEHOLDER" must be replaced before launch and is flagged on the page itself.

0.1 · THE IDEA IN ONE PARAGRAPH
────────────────────────────────────────────────────────────────────────────────
A warm, unhurried, photograph-free site for a small eye hospital in Pollachi run
by one surgeon. The ground is warm off-white, never clinical white. The recurring
graphic is the aperture — concentric lens rings drawn in hairline — because the
circle is the organ, so the motif is the subject rather than decoration. The
signature motion is a focus-pull: content arrives fractionally soft and resolves
as it enters view, which is vision itself used as the site's motion language.
Everything is sized for a worried person over fifty-five holding a phone.

0.3 · TYPOGRAPHY
────────────────────────────────────────────────────────────────────────────────
  TYPEFACE   Anek Tamil, by Ek Type (Mumbai). SIL Open Font Licence.
             One superfamily covering Latin AND Tamil, so the site reads as one
             thing in both languages rather than two fonts joined at the seam.
             Self-hosted as woff2. Never loaded from Google's CDN.
             Weights used: 400, 500, 600, 700. Nothing else.

  SCALE      Display 1    clamp(38px, 5.4vw, 63px)   700   tracking −0.028em
             Display 2    clamp(32px, 5.2vw, 54px)   700   tracking −0.028em
             H2           clamp(28px, 4.2vw, 44px)   700   tracking −0.028em
             H3           clamp(21px, 2.5vw, 27px)   700   tracking −0.02em
             H4           19px                        600   tracking −0.012em
             Lede         clamp(19px, 2.1vw, 23px)   400
             Body         18px                        400   line-height 1.66
             Small        16.5px                      400
             Caption      15px                        400   colour #6B7A81
             Eyebrow      14px  600  uppercase  tracking +0.1em  colour blue

  THE FLOOR  18px body. This is not negotiable and not a preference. The primary
             reader is over fifty-five and often reading outdoors. Any request to
             reduce it should be refused with that reason.

  MEASURE    Body paragraphs cap at 64ch. Ledes at roughly 46ch. Headlines are
             constrained in `ch` ON THE HEADING ELEMENT ITSELF, never on a parent
             div — `ch` resolves against the element's own font-size, so a `ch`
             limit on an 18px wrapper collapses a 63px headline into a narrow
             column. This is the single most common mistake in this layout.

  HEADINGS   text-wrap: balance on every heading.


0.4 · THE APERTURE — THE MOTIF
────────────────────────────────────────────────────────────────────────────────
Concentric circles, drawn as SVG, stroke only, 1px, colour #E2DACE. One ring in
the set is #0B5C8A at 45% opacity. The innermost ring may be filled #E3EEF5.

  WHERE IT APPEARS
  · Behind the home hero, right side, large, partly off-canvas.
  · Bleeding off one corner of every page hero.
  · Top-right corner of every service card, small, clipped by the card edge.
  · Bleeding off dark sections at very low opacity (0.14–0.2).
  · In the footer, bottom-right, very low opacity.

  RULES
  · Always `position:absolute`, `pointer-events:none`, `z-index:0`.
  · Always inside a container with `overflow:hidden` so it clips cleanly.
  · Always `aria-hidden="true"` — it carries no information.
  · It is never the subject of a section. It sits behind content, never over it.
  · It never animates on scroll except the one instance in 0.5.


0.5 · MOTION
────────────────────────────────────────────────────────────────────────────────
  FOCUS-PULL — the only entrance animation on the site.
    from:  opacity 0 · blur 9px · translateY 22px · scale 0.985
    to:    opacity 1 · blur 0   · translateY 0    · scale 1
    timing 0.85s  cubic-bezier(.22,.68,.28,1)
    stagger 0.09s per step, maximum five steps
    trigger IntersectionObserver, rootMargin 0 0 −12% 0, threshold 0.08, once

    APPLY TO: headings, cards, tiles, list blocks, images, buttons rows.
    NEVER APPLY TO: long body paragraphs. Blurring text somebody is trying to
    read is user-hostile and expensive on mid-range GPUs.

  HERO APERTURE — home page only. Rings scale from 0.35 to 1 with opacity 0 to 1
  on load, 1.5s, staggered 0.1s per ring from outside in. The eye opens once.

  MICRO
    Buttons          translateY(−2px) on hover, 0.25s
    Card hover       translateY(−5px) + deeper shadow, 0.35s
    Arrow links      gap 9px → 15px on hover
    Service aperture scale 1.12 + rotate 8deg on card hover
    Open-now dot     2.6s pulse ring, infinite

  OFF SWITCH
    Under prefers-reduced-motion: reduce — every animation and transition is
    disabled, the focus-pull resolves instantly, the pulse stops.
    If JavaScript never runs, a .no-js rule shows all content immediately.
    A 2.6s timeout reveals anything the observer missed. The page can never
    end up blank.

  NOT USED, DELIBERATELY
    Carousels. Smooth-scroll hijacking (Lenis and similar). Parallax.
    Any hover-dependent effect that carries meaning. Page-load overlays.
    All four are wrong for this audience and three of the four are what the
    competing chains do.

0.8 · VOICE
────────────────────────────────────────────────────────────────────────────────
  · Plain words. "Cloudy, faded or washed out", not "posterior subcapsular".
  · Second person. "You come in the morning and go home the same evening."
  · Never "world-class", "state-of-the-art", "best in class", "cutting-edge".
    Specificity beats superlatives: name the procedure, the surgeon, the year.
  · Symptoms before procedure names. Nobody arrives knowing their diagnosis.
  · Money is discussed openly and first, because that is what people are afraid
    to ask about.
  · No exclamation marks. No emoji. No stock-photo optimism.


0.9 · BILINGUAL BEHAVIOUR
────────────────────────────────────────────────────────────────────────────────
  Every translatable string is two sibling spans:
      <span lang="en">English</span><span lang="ta" class="ta">தமிழ்</span>
  The <html> element carries data-lang="en" or "ta". CSS hides the other.
  The EN/த control sits in the header, persists to localStorage, and switches
  the entire interface — navigation, buttons, labels, body — not just articles.
  Tamil is set at weight 500 to optically match Latin 400 at the same size.

  STATUS: headings, navigation, buttons and the critical blocks are translated.
  Remaining body copy needs a Tamil-speaking medical copywriter. Do not machine-
  translate medical content.

A · THE BRIEF
────────────────────────────────────────────────────────────────────────────────
Nine out of ten first-time visitors will see only this page, so it must be a
complete answer on its own. The reader is worried, on a phone, often researching
for a parent. In order, they want to know: are you open, who will see me, how do
I reach you. The page answers in that order. Seven sections. The single job is to
make the phone call happen.

does not perform.

════════════════════════════════════════════════════════════════════════════════

STYLE CARRIED THROUGH
  □ Every page uses the identical header, sticky call bar and footer.
  □ Every page hero has one aperture bleeding off a corner. Same construction,
    same stroke, only the size and opacity vary.
  □ Band order alternates. No two identical bands ever touch.
  □ At most ONE dark ink section per page. Only Home, Cataract surgery and
    Patient stories have one.
  □ Only the colours in 0.2 appear anywhere. No new hue has been introduced.
  □ Blue is used only for things that can be clicked.
  □ One typeface, four weights, no exceptions.
  □ Card anatomy is reused, never reinvented. Service cards look the same on
    Home and on Treatments.
  □ Every section that opens with a label uses the eyebrow component.

TYPOGRAPHY
  □ Body text is 18px everywhere. Nothing smaller than 15px anywhere.
  □ Every `ch` max-width sits on the element that carries the font-size, never
    on a wrapper.
  □ No paragraph exceeds 64ch.
  □ Every heading has text-wrap: balance.

MOTION
  □ Focus-pull appears on headings and cards only, never on long paragraphs.
  □ Stagger never exceeds five steps.
  □ prefers-reduced-motion disables everything.
  □ With JavaScript blocked, every page still shows all its content.

MOBILE — TEST AT 390px
  □ Zero horizontal scroll on every page.
  □ The sticky call bar is visible at every scroll depth on every page.
  □ Call bar labels stay on one line.
  □ The header brand truncates instead of pushing the menu button off-screen.
  □ Every touch target is at least 48px with 8px separation.

BILINGUAL
  □ The EN/த toggle switches navigation, buttons and body — not just articles.
  □ No English string is left visible in Tamil mode, and vice versa.
  □ Tamil renders in Anek, not a system fallback.

CONTENT — THE FOUR THINGS THAT MUST HAPPEN BEFORE LAUNCH
  □ Patient stories replaced with real, consented quotations; dashed note removed.
  □ Tamil body copy completed and checked by a Tamil-speaking medical
    copywriter. Not machine translation.
  □ Consulting days, the full treatment list and scheme coverage confirmed with
